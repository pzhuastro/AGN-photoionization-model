# AGN photoionization model
AGN photoionization model from P. Zhu et al. (2023, ApJ, 954, 2, 175). This dust-depleted, radiation-pressure-dominated model was built using updated nonlinear abundance prescriptions and the MAPPINGS V photoionization code. It reproduces the observed emission-line ratios in AGN narrow-line regions across the UV, optical, and infrared wavelengths. Emission-line fluxes in the model grids are normalized to the Hβ flux.

'AGN_NHhigh_isoB_DN_MV520.csv' contains the AGN photoionization model built with 'NHhigh' nitrogen abundance scaling relation;

'AGN_NHlow_isoB_DN_MV520.csv' contains the AGN photoionization model built with 'NHlow' nitrogen abundance scaling relation;

Please refer to P.Zhu et al., (2023) for detailed description on model settings.
