# AGN-photoionization-model-
AGN photoionization model from P. Zhu et al. (2023, ApJ, 954, 2, 175). This dust-depleted, radiation-pressure-dominated model was built using updated nonlinear abundance prescriptions and the MAPPINGS V photoionization code. It reproduces the observed emission-line ratios of AGN narrow-line regions across the UV, optical, and infrared wavelengths.
